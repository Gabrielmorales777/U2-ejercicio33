# Sistema de Motores de Renderizado Gráfico

**Objetivo principal:** Desarrollar un sistema modular en Java que permita utilizar e intercambiar diferentes motores de renderizado gráfico mediante una interfaz común.

El programa implementa la interfaz `MotorGrafico` y tres renderizadores concretos: `RenderizadorOpenGL`, `RenderizadorDirectX` y `RenderizadorVulkan`. La clase `SistemaGrafico` permite inicializar contextos, dibujar mallas y liberar recursos sin depender de una tecnología gráfica específica.

**Conceptos aplicados:**
- Interfaces y abstracción.
- Implementación de métodos.
- Polimorfismo.
- Encapsulamiento.
- Desacoplamiento.
- Validación de estados.
- Inyección de dependencias.
